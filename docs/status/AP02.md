`is_error: true`. Der Erfolg wird an `is_error` und dem Exit-Code festgemacht,
nicht an `subtype`.

## 3. Entscheidung Container-zu-Host (ADR-0022)

Die CLI kommt **nicht** ins Backend-Image, Profil B wird **nicht** gemountet.
Ein Host-seitiger Runner führt die CLI aus; das Backend spricht ihn über einen
Unix-Domain-Socket in einem Bind-Mount an. Grund: Ein Read-only-Mount von
Profil B ist nicht tragfähig — die CLI schreibt bei jedem Lauf in ihr
Config-Verzeichnis, und dort liegen unter Linux auch die Zugangsdaten.
Machbarkeit belegt: Wegwerf-Container als uid 1000 erreicht einen Host-Socket
mit Mode `0600` (exit 0), Testartefakte restlos entfernt.
